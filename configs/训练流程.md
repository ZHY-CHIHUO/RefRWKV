## 7. 故障速查表

| 症状 | 最可能原因 | 处理 |
|---|---|---|
| Stage 1 出现 CUDA IMA | Adapter 的 `RUN_CUDA` 越界 | 给 `VRWKV_SpatialMix` 的 `k`/`v` 加 `.contiguous()`；若仍崩溃，需给 Adapter 也写纯 PyTorch WKV 回退 |
| Stage 2 出现 CUDA IMA | GlobalSemanticModule 未真正用纯 PyTorch WKV | 确认 `globalsemanticmodule.py` 是 SR 条件版（含 `_wkv_scan_torch`） |
| Stage 2 loss 尖峰 3000 步不回落 | `sr_conditioner` 输出尺度异常 | 临时 `use_sr_condition: false` 跑 500 步对比 |
| Stage 3 missing keys 超出 sim_transfer | 配置传递链断裂 | 检查 `rwkv_cfg` 在 yaml 里的缩进 |
| Stage 3 LPIPS 上升 | 传播过强，纹理被"抹匀" | `self_sim_init_alpha` 降到 0.15 |
| Stage 4 `D_tex_conf` 长期 < 0.2 | 数据对齐或 ref 增强过强 | `ref_aug_probs` 全 0 跑 100 步 |
| 任何阶段 OOM | sim_transfer 亲和矩阵显存 | 确认没有误开 scale1 传播 |
