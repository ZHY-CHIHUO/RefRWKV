# UC Merced Land Use Dataset

## 数据集概况

UC Merced Land Use Dataset（也常写作 UCM、UCMerced Land Use）是用于航空影像土地利用场景分类的公开数据集，不是原生的超分辨率配对数据集。

| 属性 | 原始信息 |
| --- | --- |
| 发布说明日期 | 2010-10-28 |
| 类别数 | 21 |
| 总图像数 | 2,100（每类 100 张） |
| 图像尺寸 | 256 × 256 像素 |
| 颜色/文件格式 | 当前下载副本为 3 通道 RGB TIFF |
| 像元分辨率 | 1 英尺 |
| 影像来源 | USGS National Map Urban Area Imagery 城市区域正射影像 |
| 数据用途 | 研究用途的土地利用/航空场景分类 |

原始影像来自美国多个城市区域的大幅 USGS 影像，再人工裁剪为 256 × 256 小图。官方说明将这些影像描述为 public-domain imagery；使用时仍应遵循数据源和论文的引用要求。

## 类别

每个类别均包含 100 张图像：

1. `agricultural`：农业用地
2. `airplane`：飞机
3. `baseballdiamond`：棒球场
4. `beach`：海滩
5. `buildings`：建筑物
6. `chaparral`：灌木/丛林地
7. `denseresidential`：高密度住宅区
8. `forest`：森林
9. `freeway`：高速公路
10. `golfcourse`：高尔夫球场
11. `harbor`：港口
12. `intersection`：道路交叉口
13. `mediumresidential`：中密度住宅区
14. `mobilehomepark`：活动房屋社区
15. `overpass`：立交桥
16. `parkinglot`：停车场
17. `river`：河流
18. `runway`：跑道
19. `sparseresidential`：低密度住宅区
20. `storagetanks`：储罐
21. `tenniscourt`：网球场

## 本项目中的 SR 转换

原始 UCM 数据没有 LR、HR 或 Ref 配对。本项目使用它构造可供 `RefPNGDataset` 读取的合成 4× SISR 数据：

```text
原图 -> 中心裁剪/必要时缩放 -> HR 256×256
HR   -> PIL bicubic 下采样      -> LR 64×64
LR   -> PIL bicubic 上采样      -> Ref 256×256
```

这里的 `Ref` 不是同类别图像，也不是外部语义参考，而是当前样本 LR 的上采样结果。`configs/runs/ucmerced_x4.yaml` 使用 `data.reference_mode: lr_up`，会在运行时由当前 LR 构造该参考条件。

固定随机种子为 `42`，按类别分层切分为：

| split | 图像数 | 每类约数 |
| --- | ---: | ---: |
| train | 1,470 | 70 |
| val | 315 | 15 |
| test | 315 | 15 |

准备后的目录：

```text
data/remote_sensing/prepared/UC_Merced/
├── train/{HR,LR,Ref}/
├── val/{HR,LR,Ref}/
├── test/{HR,LR,Ref}/
├── metadata.json
└── manifest.jsonl
```

准备脚本会检查 RGB 模式、尺寸、三目录同名配对，并确认每个 `Ref` 都等于对应 `LR` 按 bicubic 上采样到 HR 尺寸的结果。镜像中少量文件的原始边长略小于标称尺寸时，脚本会先 bicubic 调整到目标 HR 尺寸，以保留该类别样本。

## 加载示例

```python
from RefSR_data.RefDataset import RefPNGDataset

dataset = RefPNGDataset(
    data_dir="data/remote_sensing/prepared/UC_Merced",
    mode="train",
    patch_size=256,
    scale=4,
    augment=False,
    augment_ref=False,
)
sample = dataset[0]
# lr: (3, 64, 64), hr/ref: (3, 256, 256), values in [-1, 1]
```

对应的训练配置为 `configs/runs/ucmerced_x4.yaml`，使用 `rwkv7` 环境启动：

```bash
conda run -n rwkv7 python scripts/train_sr_prior.py \
  --config configs/runs/ucmerced_x4.yaml
```

当前仓库只跟踪本说明和准备脚本；原始压缩包、准备后的 PNG、`metadata.json` 与 `manifest.jsonl` 均由 `.gitignore` 排除，需在本地准备后才能加载。

## 使用边界

UCM 的原始标签是场景分类标签。转换后的 HR/LR 对是由同一张图像人工合成的 bicubic SR 任务，不能解释为真实传感器采集的 LR-HR 对，也不应与原始分类基准的指标直接比较。
