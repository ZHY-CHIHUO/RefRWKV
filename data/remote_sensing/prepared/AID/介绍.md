# AID（Aerial Image Dataset）

## 数据集概况

AID（A Benchmark Dataset for Performance Evaluation of Aerial Scene Classification）是面向航空场景分类的大规模公开数据集，不是原生的超分辨率配对数据集。

| 属性 | 原始信息 |
| --- | --- |
| 数据集名称 | Aerial Image Dataset（AID） |
| 类别数 | 30 |
| 总图像数 | 10,000 |
| 图像尺寸 | 固定 600 × 600 像素 |
| 颜色/文件格式 | 当前下载副本为 3 通道 RGB JPEG |
| 影像来源 | Google Earth 影像的 RGB rendering |
| 像元分辨率 | 多分辨率，约 0.5–8 米 |
| 覆盖范围 | 中国、美国、英国、法国、意大利、日本、德国等多个国家和地区 |
| 标注 | 由遥感影像解译领域专家标注 |
| 原始任务 | 航空场景分类 |

AID 使用来自不同遥感传感器、地区、季节和成像条件的影像，因此同一类别内部变化较大；不同类别之间也可能共享相似的地物和结构。固定的 600 × 600 像素对应不同地面覆盖范围，这是 AID 多分辨率设计的一部分。

## 本项目中的 SR 转换

原始 AID 没有 LR、HR 或 Ref 配对。本项目从每张 600 × 600 原图中心裁剪 512 × 512 HR，并构造 4× SISR 输入：

```text
原图 -> 中心裁剪 -> HR 512×512
HR   -> PIL bicubic 下采样 -> LR 128×128
LR   -> PIL bicubic 上采样 -> Ref 512×512
```

这里的 `Ref` 不是另一张 AID 图像，也不包含额外语义信息；它只是当前样本 LR 的 HR 尺寸 bicubic 上采样。`configs/runs/aid_x4_l1.yaml` 使用 `data.reference_mode: lr_up`，会在运行时由当前 LR 重建该参考条件。

固定随机种子为 `42`，按类别分层切分为：

| split | 图像数 |
| --- | ---: |
| train | 7,000 |
| val | 1,507 |
| test | 1,493 |

这不是 AID 官方分类论文规定的唯一训练/测试划分，而是本项目为 SR 实验生成的固定切分。准备后的目录：

```text
data/remote_sensing/prepared/AID/
├── train/{HR,LR,Ref}/
├── val/{HR,LR,Ref}/
├── test/{HR,LR,Ref}/
├── metadata.json
└── manifest.jsonl
```

准备脚本会检查 RGB 模式、目标尺寸、三目录同名配对，并确认每个 `Ref` 都等于对应 `LR` 按 bicubic 上采样到 HR 尺寸的结果。

## 加载示例

```python
from RefSR_data.RefDataset import RefPNGDataset

dataset = RefPNGDataset(
    data_dir="data/remote_sensing/prepared/AID",
    mode="train",
    patch_size=512,
    scale=4,
    augment=False,
    augment_ref=False,
)
sample = dataset[0]
# lr: (3, 128, 128), hr/ref: (3, 512, 512), values in [-1, 1]
```

对应的训练配置为 `configs/runs/aid_x4_l1.yaml`，使用 `rwkv7` 环境启动：

```bash
conda run -n rwkv7 python scripts/train_sr_prior.py \
  --config configs/runs/aid_x4_l1.yaml
```

当前仓库只跟踪本说明和准备脚本；原始压缩包、准备后的 PNG、`metadata.json` 与 `manifest.jsonl` 均由 `.gitignore` 排除，需在本地准备后才能加载。

## 使用边界

AID 的原始标签是航空场景分类标签。转换后的 HR/LR 对由 bicubic 退化合成，不能当作真实传感器 LR-HR 对；AID 原始影像来自 Google Earth RGB rendering，使用时应遵守数据源的许可和使用条款，并保留原论文引用。
