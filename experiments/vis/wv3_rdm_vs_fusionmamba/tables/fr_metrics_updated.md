# 全分辨率真实数据（FR）评估指标对比表 (Real WorldView-3)

- 测试集：20 张真实拍摄无降采样全分辨率图像，LR MS: 8×128×128, PAN: 1×512×512, Scale: x4
- 评测指标：QNR Toolbox 协议无参考指标 ($D_\lambda$ 光谱失真, $D_s$ 空间失真, QNR 综合指数)
- 对比核心：
  - **FusionMamba 官方原版**：来自作者开源 `.mat` 结果；
  - **RDM-PAN v1**：存在严重高光外推过冲，导致真实图像大面积白斑伪影，$D_s$ 高达 0.0375；
  - **RDM-PAN v5 (Ours)**：自适应门控消除伪影，全面取得最佳 QNR。
