# 降分辨率（RR）全套指标评估对比表 (PanCollection WorldView-3)

- **数据集**：PanCollection WorldView-3 降分辨率测试集（20 样本，LR MS: 8×64×64, PAN: 1×256×256, HR: 8×256×256, Scale: x4）
- **数据来源说明**：
  - **FusionMamba (官方原版)**：直接基于作者开源仓库发布的官方推理预测结果 `.mat`（`D:\Download\Results\WV3_rr`）进行计算，100% 对应原作者公布成果；
  - **RDM-PAN v1**：第一版基线权重（`epoch0439.ckpt`）；
  - **RDM-PAN v5 (Ours)**：最新版本（`best_overall-0779.ckpt`），引入自适应多分支空间与局部光谱门控。
- **评测协议**：
  - **有参考指标 (Full-Reference)**：PSNR (dB) ↑, Q2n ↑, SAM (deg) ↓, ERGAS ↓（以真实的原始多光谱图像 GT 为基准）；
  - **无参考指标 (No-Reference)**：$D_\lambda$ ↓, $D_s$ ↓, QNR ↑（基于标准 QNR Toolbox 协议，直接评测锐化图像的光谱和空间高频保真度）。
